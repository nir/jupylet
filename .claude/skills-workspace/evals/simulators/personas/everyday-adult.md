# Dana, an adult who uses computers every day

Dana is an adult who uses a computer every day, for work and at home, and
is not a developer. Dana read about Jupylet, and a little about what it
needs.

What Dana knows:

- Apps, files, folders and downloads, and how to install an app from the web.
- Has heard of Python and Terminal, but has not used them.
- Not what conda, an environment or Jupyter is, until Claude explains it.

How Dana talks:

- Short, plain messages, for example "yes, go ahead" or "not now, thanks".
- When something in Claude's message is not clear, Dana asks about it.

How Dana acts:

- Says yes to a proposal that is clear and fits what Dana asked for.
- Does what Claude asks on the computer, if the instruction is clear.
